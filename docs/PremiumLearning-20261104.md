# WatchNest premium transformation — project learning

This records bounded, observed lessons; it is not a final product acceptance.

1. Inspect message states inside the player shell even when player code is frozen.
   White text inherited from a dark shell made the white Time's Up panel unreadable.
   Repair foreground/background at the exact paper-panel boundary; do not touch
   media lifecycle, navigation guards or fullscreen to fix presentation.
2. Scoped label rules can defeat a reusable selection-row class. The parent
   collection editor displayed detached titles and checkbox-only bars because a
   form label selector had greater specificity. Explicit selectable rows and
   rendered phone/tablet/desktop rechecks are stronger than a source-only claim.
3. Screenshot scroll commands must be verified. Smooth scrolling caused top,
   middle and bottom labels to refer to the wrong actual region. Capture uses
   instant scrolling, settled frames and measured coordinates. Preserve original
   failed evidence and disclose capture-only interventions on the baseline.
4. Treat a failed locator separately from an app failure. A framework route
   announcer also has role alert; matching the actual application error text
   preserves the assertion without conflating the two. Retain failed CI runs.
5. Paused and expired need different language and actual state assertions. A
   screenshot labelled paused that still says Time's Up is an evidence conflict,
   not an acceptable state name. Keep the denial boundary identical.
6. Cold review requires fresh context. Two preliminary review agents inherited
   findings through parent history and were disqualified from cold status.
   Supplemental observations remain useful; fresh-context reviewers perform the
   real independent journeys. A role label cannot erase inherited information.
7. Candidate manifests should bind the checked-out source tree, PR head, clean
   worktree, harness/fixture hashes and actual pixels. CI merge commit names may
   differ from PR source while their complete trees match; prove equivalence.
8. Neutral asset crops and coordinates help coverage but do not prove inspection.
   Reviewers must actually consume readable pixels, record limits and avoid
   turning repeated asset instances into invented independent approvals.
9. Production-only backend configuration does not automatically reach a preview.
   A READY preview and synthetic browser suite cannot certify authenticated
   hosted workflows or physical iPad playback. Do not widen credential exposure
   to every preview branch merely for convenient QA.

Preserve mandatory Safe Playback and the existing physical-device release gate.
No synthetic browser evidence is promoted to genuine YouTube, Safari/PWA, native
fullscreen or remote picture/sound stop acceptance.
