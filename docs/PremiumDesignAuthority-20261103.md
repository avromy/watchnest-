## Chosen direction

Warm family screening room: evergreen navigation and anchor surfaces, ivory
canvas, restrained amber identity accents, real content artwork, readable type,
calm spacing and short task-led copy. Established WatchNest mark retained.
No unsolicited autoplay, gradients, babyish decoration, fake metrics or provider
recommendations. Child approved-library search stays distinct from requests.

Palette: evergreen #143e35, action #173e34, ivory #f8f6f0, ink #172b27,
muted #52655b, amber #e3c27d. Native Avenir/system font stack avoids third-party
font requests. 4/8px spacing family; content widths remain bounded. Existing
consistent SVG Icon family, visible focus, 44px minimum essential controls.
Navigation/actions may adapt to device; no hover-only essential functionality.

## Experience goals

Child: large personal profile tiles, immediate Home/Library/Ask Parent,
findable favorites/recent/Collections, direct library search/sort, secondary Hide,
non-playable request results, clear empty/pending/error states. Native playback
and Time's Up logic retained. Parent: task-led navigation, prominent Add videos,
readable selection/approval flows, requests and child controls easy to reach on
phone, truthful server-confirmed timer status and protected Parent transitions.
