# Visual evidence

These PNGs capture actual Chromium rendering of the built app with browser-only **synthetic API fixtures**, not a deployed or authenticated family. Fixture thumbnails are deliberately empty. They are limited layout/state evidence and must not be used as proof of real YouTube metadata, family accounts, analytics, persistence, Safari behavior or full visual acceptance.

Current final-family-beta evidence is generated by `e2e/visual.spec.ts`:
`profile-picker-tablet-synthetic.png`, `child-tablet-synthetic.png`,
`parent-overview-synthetic.png`, `parent-children-synthetic.png`,
`parent-settings-tablet-synthetic.png`, and
`parent-add-videos-tablet-synthetic.png`.

`child-simple-synthetic.png` is preserved only as historical September
evidence and is excluded from current-candidate review.

Reproduce: `npm ci`, `npm run build`, `npm run test:e2e`. The responsive
stress test covers 360, 390, 412, 520, 640, 768, 900, 1024, 1180, 1280, and
1440 px Parent widths plus representative child/profile-picker widths.
